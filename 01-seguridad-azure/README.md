# 🔐 01-seguridad-azure

## 🧾 Descripción
Este módulo recoge la configuración inicial de seguridad en Azure y Entra ID, junto con una práctica introductoria de autenticación mediante una API local. El objetivo es establecer una base sólida para comprender los principios fundamentales de identidad, seguridad y control de acceso en entornos Azure.

## 🎯 Objetivos del módulo
- Comprender la estructura básica de Entra ID.
- Realizar la configuración inicial del tenant.
- Crear y probar una API local como práctica de autenticación.
- Documentar bitácoras y evidencias del proceso.

## 🗂️ Contenido del módulo
- `bitacora/` — registros diarios del trabajo realizado.
- API Local — práctica inicial de autenticación (repositorio independiente).
- `README.md` — documento principal del módulo.

## 🔗 Repositorio de la API Local
https://github.com/lanuzalorenzo/lab-api-local-azure

## 🧩 Actividad: API local con autenticación
Durante el módulo se realizó una práctica inicial creando una API local con autenticación básica.  
El código se encuentra en un repositorio independiente, pero la actividad forma parte del aprendizaje del módulo.

## 🧪 Validaciones realizadas
- Tenant configurado correctamente.
- API local probada en entorno de laboratorio.
- Documentación generada y organizada.
- Bitácoras completas y estructuradas.
