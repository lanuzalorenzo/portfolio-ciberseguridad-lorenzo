# 📄 Bitácora — API Local Inicial

## 📘 Proyecto
Portfolio de Ciberseguridad — Módulo 01: Seguridad en Azure

## 🎯 Objetivo del día
Crear una API REST básica en .NET que sirva como práctica inicial de autenticación y como base para futuras integraciones con Azure.

---

## 🛠 Trabajo realizado

### 1. Instalación del SDK de .NET
- Instalación del SDK de .NET.
- Verificación del entorno de desarrollo.

### 2. Creación del proyecto base
- Generación de una Web API con plantilla estándar.
- Configuración inicial del proyecto y dependencias.

### 3. Modelado de entidades
- Creación de los modelos `Product` y `Order`.
- Definición de propiedades y namespaces.

### 4. Implementación de controladores
- Controlador de productos con operaciones básicas.
- Controlador de pedidos con operaciones básicas.
- Almacenamiento temporal en memoria para pruebas.

### 5. Configuración de Swagger y CORS
- Activación de documentación automática.
- Configuración de CORS para permitir desarrollo local.

### 6. Configuración de archivos de entorno
- Ajustes en `appsettings.json` y `appsettings.Development.json`.
- Configuración de logging y parámetros base.

### 7. Documentación auxiliar generada
- README técnico del proyecto.
- tests.md con ejemplos de pruebas.
- azure-ad-notes.md con conceptos clave de autenticación.
