# Bitácora – Ejercicio 02: Passwordless

## Día 1
- Activación de Microsoft Authenticator en Entra ID.
- Activación de Passkey (FIDO2).
- Activación de Windows Hello for Business.

## Día 2
- Detección del problema: usuario EXT no soporta passwordless.
- Creación de usuario nativo del tenant.

## Día 3
- Inicio de sesión del usuario de prueba.
- Registro de MFA.
- Registro de Authenticator passwordless.
- Validación del flujo de configuración.

## Estado final
Passwordless operativo y validado.
