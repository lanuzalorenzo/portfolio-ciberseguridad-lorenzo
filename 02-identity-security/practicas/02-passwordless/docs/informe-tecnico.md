# 📄 Informe técnico — Passwordless en Microsoft Entra ID

## 1. Introducción
La autenticación sin contraseña reduce riesgos asociados a credenciales débiles, phishing y ataques de relleno de credenciales.

## 2. Métodos habilitados
- Microsoft Authenticator (passwordless)
- FIDO2 Security Keys
- Windows Hello for Business

## 3. Configuración
- Activación desde Authentication Methods.
- Registro desde My Sign-Ins.
- Validación en portal de Microsoft.

## 4. Conclusión técnica
Passwordless es un pilar fundamental del modelo Zero Trust.
