# RBAC | Ejercicio 05

Diseño y revisión de un modelo de control de acceso basado en roles, con atención al mínimo privilegio y la separación de funciones.

## Procedimiento

- Definir roles funcionales y permisos asociados.
- Revisar las asignaciones y detectar privilegios excesivos.
- Ajustar los roles de operador y auditor.

## Modelo revisado

- `admin`: lectura, escritura y eliminación.
- `auditor`: lectura y auditoría.
- `operador`: lectura y escritura.

## Validación

El documento técnico registra la revisión de permisos directos, roles huérfanos o contradictorios y el principio de mínimo privilegio.
