# Managed Identities | Ejercicio 07

Uso de una identidad administrada en Azure para conceder acceso a recursos sin guardar credenciales de aplicación.

## Procedimiento

- Crear una identidad administrada.
- Asignar roles RBAC en el ámbito requerido.
- Validar el acceso desde el servicio o script asociado.
- Revisar permisos y registros de auditoría.

## Validación

El informe técnico registra el acceso, las asignaciones y los ajustes realizados conforme al mínimo privilegio.
