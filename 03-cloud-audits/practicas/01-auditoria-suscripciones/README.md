# Auditoría de suscripciones

Revisión del ámbito de suscripción para entender su configuración, los accesos asignados y los controles de seguridad aplicados.

## Procedimiento

1. Revisar las propiedades principales de la suscripción.
2. Identificar roles y permisos críticos.
3. Examinar configuraciones de seguridad relevantes.
4. Registrar el alcance y los hallazgos en el informe.
