# 🧪 Práctica 01 — Auditoría de suscripciones

## 🎯 Objetivo  
Realizar una auditoría inicial de suscripciones cloud, identificando configuraciones relevantes, permisos, roles asignados y posibles riesgos de seguridad asociados a la gestión de la suscripción.

## 🔧 Pasos  
1. Revisar la suscripción y sus propiedades principales.  
2. Identificar roles asignados y permisos críticos.  
3. Analizar configuraciones de seguridad relevantes.  
4. Documentar hallazgos en el informe técnico.  

## 📁 Evidencias  
Documentación técnica generada en `docs/` con los hallazgos, validaciones y configuraciones revisadas durante la auditoría.

## 📘 Conclusiones  
Resumen de los hallazgos principales, riesgos detectados y recomendaciones iniciales para mejorar la seguridad de la suscripción.
