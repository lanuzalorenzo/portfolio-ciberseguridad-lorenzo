# Activación de planes de Defender for Cloud

La práctica recorre la selección y activación de planes de protección en una suscripción de laboratorio.

## Procedimiento

1. Revisar los planes disponibles para la suscripción.
2. Seleccionar los planes dentro del alcance del laboratorio.
3. Activarlos desde Defender for Cloud.
4. Comprobar el estado de los planes y las capacidades relacionadas.
