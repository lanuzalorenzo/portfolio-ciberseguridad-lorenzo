# Revisión de recomendaciones de seguridad

La práctica utiliza las recomendaciones de Defender for Cloud para revisar prioridades y cambios potenciales en la postura de seguridad.

## Procedimiento

1. Revisar las recomendaciones disponibles y el Security Score.
2. Priorizar las recomendaciones relevantes para el alcance.
3. Aplicar los cambios seleccionados.
4. Comprobar el estado resultante y documentar las observaciones.
