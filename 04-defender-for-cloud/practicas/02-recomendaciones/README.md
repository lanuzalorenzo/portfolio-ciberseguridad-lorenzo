# 🧪 Práctica 02 — Recomendaciones

## 🎯 Objetivo
Analizar, priorizar y aplicar recomendaciones de seguridad generadas por Microsoft Defender for Cloud para mejorar la postura de seguridad de la suscripción.

## 🔧 Pasos
1. Acceder al panel de recomendaciones.
2. Revisar el Security Score.
3. Identificar recomendaciones críticas.
4. Aplicar las recomendaciones seleccionadas.
5. Validar el impacto en el Security Score.
6. Registrar evidencias.

## 📁 Evidencias
- Capturas del Security Score inicial.
- Recomendaciones aplicadas.
- Security Score final.

## 📘 Conclusiones
La aplicación de recomendaciones mejora la postura de seguridad y reduce riesgos operativos.
