# 🛡️ 04-devsecops

**Estado:** 🟢 Finalizado

## 🧾 Descripción
Este módulo introduce prácticas DevSecOps orientadas a mejorar la seguridad, trazabilidad y control del ciclo de vida del código en todos los repositorios del portfolio.

El enfoque principal es aplicar medidas que garanticen integridad en la rama `main`, evitando cambios no revisados y asegurando que todo el código pasa por procesos de validación.

## 🎯 Objetivos del módulo
- Implementar controles de seguridad en el flujo de trabajo Git.
- Proteger la rama `main` en todos los repositorios.
- Garantizar trazabilidad y aprobación en cada cambio.
- Documentar evidencias y configuración aplicada.

## 🗂️ Prácticas incluidas
- **01-proteccion-rama-main/**  
  Práctica donde se configuran reglas de protección de rama en GitHub para asegurar integridad y control de versiones.

## 📚 Documentación
Cada práctica incluye:
- Pasos técnicos detallados.
- Evidencias de configuración.
- Repositorios donde se ha aplicado.

## 🏁 Conclusiones
El módulo 4 establece una base DevSecOps sólida para el portfolio, asegurando que el código evoluciona con controles de seguridad y revisión obligatoria.
