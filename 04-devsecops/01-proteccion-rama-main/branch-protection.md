# 🔧 Configuración técnica de protección de la rama `main`

Reglas aplicadas en GitHub:

- Require a pull request before merging  
- Require approvals  
- Require conversation resolution before merging  
- Require linear history  
- (Opcional) Restricciones adicionales según el proyecto

## 🪜 Procedimiento
1. Crear repositorio plantilla vacío.  
2. Activar **Template repository**.  
3. Crear `README.md` para generar la rama `main`.  
4. Ir a **Settings → Branches**.  
5. Crear regla de protección para `main`.  
6. Usar la plantilla para todos los repos futuros.
