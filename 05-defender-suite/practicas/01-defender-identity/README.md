# Práctica 01 | Defender for Identity

## Objetivo
Configurar sensores de Defender for Identity, integrar Active Directory y validar alertas de identidades comprometidas.

## Recorrido de la práctica
1. Revisar requisitos del sensor.
2. Descargar el paquete desde el portal de Defender for Identity.
3. Instalar el sensor en el controlador de dominio.
4. Validar conectividad con el servicio.
5. Revisar alertas generadas.
6. Documentar resultados en informe técnico y conclusiones.

## Contexto técnico
La integración permite detectar movimientos laterales, Pass-the-Hash, Pass-the-Ticket y anomalías de identidad en tiempo real.
