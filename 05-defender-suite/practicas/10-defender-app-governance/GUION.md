# Guion — Práctica 10: Defender App Governance

> **En fácil:** este guion revisa qué aplicaciones tienen permiso para leer datos de la organización y si alguna se comporta de forma rara. Es el control de quién tiene llave y qué hace con ella.

## Objetivo

Evaluar y controlar permisos, comportamientos y riesgos de aplicaciones OAuth y de aplicaciones con acceso a datos en Microsoft 365 mediante App Governance.

## Contexto técnico

App Governance permite:

- Visibilidad sobre aplicaciones OAuth.
- Análisis de permisos y accesos.
- Detección de comportamientos anómalos.
- Alertas de riesgo.
- Integración con Defender XDR.

## Preparación del entorno

1. Activar App Governance.
2. Validar los permisos del usuario.
3. Confirmar la ingestión de datos desde Microsoft 365.

## Revisión de aplicaciones OAuth

1. Revisar las aplicaciones registradas.
2. Validar los permisos concedidos.
3. Revisar los accesos a datos sensibles.
4. Identificar las aplicaciones de alto riesgo.

## Comportamientos anómalos

1. Revisar la actividad de las aplicaciones.
2. Validar las acciones sospechosas.
3. Revisar las alertas generadas.

## Recomendaciones de seguridad

1. Revisar las recomendaciones.
2. Validar las configuraciones inseguras.
3. Revisar las acciones sugeridas.

## Integración con XDR

1. Revisar los incidentes relacionados.
2. Validar la correlación con señales de Microsoft 365.

## Cierre

1. Evaluar el riesgo de las aplicaciones.
2. Identificar mejoras futuras.
3. Registrar en bitácora al final del módulo.
