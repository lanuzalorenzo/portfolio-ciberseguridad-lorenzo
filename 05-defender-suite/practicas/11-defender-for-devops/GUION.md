# Guion — Práctica 11: Defender for DevOps

> **En fácil:** este guion conecta el código y las tuberías de entrega a Defender para que revise la infraestructura, los secretos y las dependencias. Es poner un revisor en la puerta antes de publicar.

## Objetivo

Integrar repositorios y pipelines con Defender for DevOps para habilitar análisis de seguridad, detección de secretos, evaluación de IaC y protección de la cadena de suministro.

## Contexto técnico

Defender for DevOps permite:

- Escaneo de IaC.
- Detección de secretos expuestos.
- Análisis de dependencias vulnerables.
- Protección de la cadena de suministro.
- Integración con GitHub y Azure DevOps.
- Correlación con Defender XDR.

## Preparación del entorno

1. Conectar GitHub o Azure DevOps.
2. Validar permisos.
3. Confirmar la ingestión de repositorios.

## Revisión de repositorios

1. Revisar los repositorios integrados.
2. Validar el estado de seguridad.
3. Revisar las configuraciones de protección.

## Escaneo de IaC

1. Revisar los escaneos de Terraform, Bicep y ARM.
2. Validar las configuraciones inseguras.
3. Revisar las recomendaciones.

## Detección de secretos

1. Revisar los secretos expuestos.
2. Validar las credenciales detectadas.
3. Revisar las acciones sugeridas.

## Análisis de dependencias

1. Revisar las vulnerabilidades en dependencias.
2. Validar las CVEs detectadas.
3. Revisar el impacto en los pipelines.

## Alertas

1. Revisar las alertas generadas.
2. Validar la correlación con XDR.
3. Revisar los incidentes relacionados.

## Cierre

1. Evaluar la seguridad del pipeline.
2. Identificar mejoras futuras.
3. Registrar en bitácora al final del módulo.
