# 06 | Privileged Access & Identity Governance

Este módulo se centra en la protección del acceso privilegiado y la gobernanza de identidades en Microsoft Entra ID. Mientras el módulo 01 explica la autenticación y el flujo de tokens, este bloque se enfoca en cómo controlar, limitar, auditar y reforzar el acceso a los recursos críticos del entorno.

## Registro del trabajo

Las [bitácoras del módulo](bitacora/) registran la evolución del laboratorio, los controles aplicados y las decisiones de seguridad adoptadas.

## Alcance

El módulo cubre escenarios de identidad, acceso privilegiado y gobernanza en entornos Microsoft Entra ID y Azure. Está orientado a laboratorios y validación de controles, no a una implantación de producción.
