# Protección de la rama principal

Esta práctica define un control de cambios para repositorios GitHub: las modificaciones a `main` deben pasar por revisión y conservar trazabilidad.

## Política documentada

- Requerir Pull Request para integrar cambios.
- Requerir al menos una aprobación.
- Bloquear el borrado y el `force-push` de `main`.
- Evitar la escritura directa en la rama protegida.

## Alcance y validación

La política describe el baseline del portfolio. La configuración se debe comprobar en los ajustes de cada repositorio: este documento no contiene una exportación de reglas ni permite afirmar por sí solo que estén aplicadas globalmente.
