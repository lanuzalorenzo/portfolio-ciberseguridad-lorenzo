# 08 | Seguridad de red en Azure

Este módulo aborda controles de red que reducen la exposición y limitan los flujos entre cargas de trabajo y servicios de Azure. Se centra en segmentación, control de tráfico y conectividad privada.

## Prácticas

- [Segmentación con VNet y Network Security Groups](practicas/01-segmentacion-vnet-nsg/README.md)
- [Control centralizado de tráfico con Azure Firewall](practicas/02-control-trafico-firewall/README.md)
- [Acceso privado a servicios con Private Link](practicas/03-acceso-privado-private-link/README.md)

## Registro del trabajo

La [bitácora del módulo](bitacora/) registra las decisiones de alcance y la evolución de los laboratorios.

## Alcance

El módulo se plantea como una serie de laboratorios, no como una configuración desplegada. Cada práctica define su objetivo y validaciones pendientes; los resultados se documentarán solo después de ejecutar las pruebas. Antes de aprovisionar recursos se deben comprobar disponibilidad, permisos y costes del entorno.
