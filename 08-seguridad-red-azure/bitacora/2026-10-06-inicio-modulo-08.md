# Bitácora — Inicio del módulo 08

## Contexto y alcance

Este módulo se documenta como un ejercicio técnico con enfoque en aprendizaje, validación y trazabilidad del trabajo realizado.

## Objetivo

Definir un módulo de seguridad de red en Azure que amplíe el portfolio con controles de segmentación, inspección de tráfico y conectividad privada.

## Alcance acordado

- Segmentación de una red virtual y definición de flujos mediante Network Security Groups.
- Diseño de control centralizado del tráfico con Azure Firewall, sujeto a revisar coste y disponibilidad antes de desplegar.
- Acceso privado a un servicio PaaS mediante Private Link y resolución DNS privada.
