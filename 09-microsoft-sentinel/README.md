# 09 | Microsoft Sentinel

Este módulo abre la capa de detección, investigación y respuesta operativa en Microsoft Sentinel. El enfoque es seguir la misma lógica que el resto del portfolio: identificar un problema de seguridad, documentar la arquitectura de observabilidad y dejar claro qué validaciones se ejecutarán o quedan pendientes.

## Registro del trabajo

La [bitácora del módulo](bitacora/) recoge el planteamiento del laboratorio y la evolución del caso de uso.

## Alcance

El módulo se plantea como un enfoque de laboratorio de seguridad operativa, no como una implementación de producción. Hace foco en la unión entre fuentes de datos, detección y automatización del análisis para escenarios de Azure y Microsoft 365.
