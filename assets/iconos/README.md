# Icono del repositorio

Un único SVG, `portfolio.svg`, usado en la cabecera del README y como icono de la carpeta del repositorio.

- Glifo: `map-marker-path` (ruta con destino).

Formato: 64×64, `rx=16`, fondo navy con degradado (`#07131e` → `#0e2a47`) y glifo blanco relleno (`#f8fafc`). Sin etiqueta ni color por repositorio: la distinción va en el glifo.

## Origen y licencia

El glifo procede de [Material Design Icons](https://pictogrammers.com/library/mdi/) (Pictogrammers), licencia [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0). Está recoloreado y compuesto; la geometría del glifo no se ha modificado.
