# Plantillas

Se copian, no se leen como documentación. Cada práctica tiene un solo nivel: `README.md` y, si hace falta, `informe.md`.

| Plantilla | Cuándo se usa |
|---|---|
| [`README-practica-template.md`](README-practica-template.md) | Página de una práctica: qué se hizo, resultado y enlaces. Extensión orientativa, 240–310 palabras. |
| [`runbook-template.md`](runbook-template.md) | Procedimiento que alguien pueda repetir: requisitos, pasos y validación. |
| [`evidencia-template.md`](evidencia-template.md) | Registro fechado de una ejecución o de una decisión, con su resultado y limitaciones. |

Un runbook preparado no es una validación: si no se ejecutó, el estado es **Runbook preparado**.
