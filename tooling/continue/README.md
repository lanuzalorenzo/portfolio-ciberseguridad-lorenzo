# 🧰 Continue — Configuración y Uso en el Portfolio

Este directorio contiene la configuración y documentación relacionada con Continue,
la herramienta utilizada para automatizar flujos de trabajo y asistencia en el desarrollo
del portfolio de ciberseguridad.

## 📄 Archivos

- **continue.md**  
  Documento principal con instrucciones, prompts y configuración de uso de Continue.

## 🎯 Propósito

Centralizar la configuración de Continue dentro del portfolio, manteniendo una arquitectura
ordenada y separada de notas privadas o contenido no relacionado.
